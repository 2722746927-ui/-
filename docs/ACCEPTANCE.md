# V0.1 人工验收清单

上线真实体验前需使用服务端真实 DeepSeek 密钥完成以下验证；不要使用真实敏感信息进行测试。

1. 学生、不知道方向：第一轮说明无明确职业目标；第二轮应从真实经历和满足感探索，第三轮关注学业和低成本试验。
2. 希望旅行的职场人：填写自由、旅行、稳定收入的取舍；后续应确认经济来源、工作形式与现实责任，不直接建议辞职。
3. 有明确目标的转行者：填写现有技能和预算；追问应针对门槛、技能差距和尝试机会，报告给出至少两条可比较路线。
4. 在每轮中途刷新，确认恢复；返回修改第一轮，确认后续问题与旧报告失效。
5. 部分跳过、不知道和很少信息的情况，应诚实标记未知，不虚构学历、收入和能力。全部跳过不能生成虚构报告。
6. 检查手机 375px、平板、电脑布局；中文报告不溢出；键盘可完成操作；加载及错误提示可读。
7. 下载 PDF，检查中文、长段落、跨页和页码；浏览器打印作为备用。
8. 清除数据后刷新，确认回答与报告消失；检查 GitHub 和前端 JS 没有 API 密钥。
9. 观察实际模型延迟、报告具体性和模型成本，再逐步放大体验人数。
